## Task 5: Clean Up Your GitHub Account

### Repository Cleanup

- [ ] Review empty or abandoned repositories.
- [ ] Archive projects that are no longer maintained but should be preserved.
- [ ] Rename repositories with unclear names when appropriate.
- [ ] Remove duplicate or irrelevant pinned projects.
- [ ] Verify repository links and documentation.

### Security Audit

- [ ] Check for accidentally committed `.env` files.
- [ ] Search for exposed API keys, access tokens, and passwords.
- [ ] Review commit history if secrets may have been committed.
- [ ] Add sensitive local files to `.gitignore`.
- [ ] Revoke or rotate any exposed credentials.

**Important:** Adding a file to `.gitignore` does not remove it from Git history. Exposed credentials should be revoked or rotated immediately.
